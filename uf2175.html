Preguntas Cortas

1. Explica qué es la independencia de los datos.

La independencia de los datos permite modificar la estructura física o lógica sin afectar a las aplicaciones que utilizan la base de datos.

2. ¿Qué función tiene una clave ajena?

Una clave ajena permite relacionar registros de una tabla con otra tabla.

3. ¿Qué ventajas aporta la normalización de bases de datos?

Reduce redundancias, mejora la integridad de los datos y facilita el mantenimiento.

Caso Práctico

Una biblioteca desea almacenar información sobre:

  • Libros
  • Socios
  • Préstamos
  • Autores

Apartado 1 - Entidades y atributos

Identifica las entidades y sus atributos principales.

Entidades:
  • Libro
  • Socio
  • Préstamo
  • Autor
Atributos:
  • Libro → ISBN, título, editorial
  • Socio → código, nombre, teléfono
  • Préstamo → fecha_inicio, fecha_fin
  • Autor → código, nombre

Apartado 2 - Relaciones

Indica las relaciones y cardinalidades.

Autor 1:N Libro

Socio 1:N Préstamo

Libro 1:N Préstamo

Apartado 3 - Modelo relacional

Diseña las tablas y sus claves.

AUTORES(id_autor PK, nombre)

LIBROS(isbn PK, titulo, editorial, id_autor FK)

SOCIOS(id_socio PK, nombre, telefono)

PRESTAMOS(id_prestamo PK, fecha_inicio, fecha_fin, isbn FK, id_socio FK)

Apartado 4 - Normalización

Explica en qué forma normal se encuentran las tablas.

Las tablas cumplen 1FN, 2FN y 3FN. No existen grupos repetitivos, dependencias parciales ni transitivas.

Apartado 5 - Restricciones de integridad

Propón dos restricciones de integridad para la base de datos.

1. El ISBN debe ser único.

2. Un préstamo no puede referenciar un socio inexistente.
