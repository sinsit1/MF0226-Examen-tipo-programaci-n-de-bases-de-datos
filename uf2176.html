Parte teórica

Pregunta 1. ¿Qué diferencia existe entre una clave primaria y una restricción UNIQUE?

La clave primaria identifica de forma única cada registro y no admite NULL. UNIQUE evita duplicados pero puede admitir NULL.

Pregunta 2. Explica para qué sirven CHECK y DEFAULT.

CHECK valida condiciones sobre los datos y DEFAULT asigna valores automáticos.

Pregunta 3. ¿Qué ventajas aporta utilizar índices?

Mejoran la velocidad de búsqueda y consulta de registros.

Pregunta 4. ¿Qué es un JOIN?

Permite combinar información procedente de varias tablas relacionadas.

Pregunta 5. Diferencia entre INSERT y UPDATE.

INSERT añade registros nuevos y UPDATE modifica registros existentes.

Pregunta 6. ¿Qué problemas ayudan a evitar las transacciones?

Evitan inconsistencias cuando varias operaciones deben completarse juntas.

Pregunta 7. ¿Para qué sirve ALTER TABLE?

Permite modificar la estructura de una tabla existente.

Pregunta 8. Indica los comandos para crear una vista, eliminar una tabla y confirmar una transacción.

CREATE VIEW, DROP TABLE y COMMIT.

Práctica SQL

Apartado a

Mostrar el nombre de todos los empleados.

SELECT nombre FROM EMPLEADOS;

Apartado b

Mostrar los proyectos con presupuesto superior a 10000 €.

SELECT * FROM PROYECTOS WHERE presupuesto > 10000;

Apartado c

Mostrar todos los proyectos ordenados por presupuesto descendente.

SELECT * FROM PROYECTOS ORDER BY presupuesto DESC;

Apartado d

Insertar un nuevo empleado llamado Pedro.

INSERT INTO EMPLEADOS (id_empleado, nombre) VALUES (4, 'Pedro');

Apartado e

Incrementar un 10% el presupuesto del proyecto ERP.

UPDATE PROYECTOS SET presupuesto = presupuesto * 1.10 WHERE nombre = 'ERP';

Apartado f

Eliminar proyectos con presupuesto inferior a 5000.

DELETE FROM PROYECTOS WHERE presupuesto < 5000;

Apartado g

Crear una tabla CLIENTES.

CREATE TABLE CLIENTES(id_cliente INT PRIMARY KEY,nombre VARCHAR(50));

Apartado h

Crear una vista con nombre y departamento.

CREATE VIEW vista_empleados AS SELECT nombre,departamento FROM EMPLEADOS;

Apartado i

Añadir una columna email a EMPLEADOS.

ALTER TABLE EMPLEADOS ADD email VARCHAR(100);

Apartado j

Explica una ventaja de las vistas.

Permiten simplificar consultas complejas y limitar el acceso a determinados datos.
