Programación y procedimientos almacenados

Variables, estructuras de control, procedimientos, funciones y transacciones en PL/SQL.

7 preguntas cortas6 ejercicios PL/SQL
Parte teórica Práctica

Parte teórica

Pregunta 1. ¿Qué es un entorno de desarrollo integrado (IDE)?

Un IDE es una aplicación que integra editor de código, depurador y otras herramientas para facilitar el desarrollo.

Pregunta 2. ¿Qué es una variable y para qué se utiliza?

Una variable es un espacio de memoria que almacena datos que pueden cambiar durante la ejecución.

Pregunta 3. Explica la diferencia entre un procedimiento almacenado y una función.

Una función devuelve un valor. Un procedimiento realiza acciones y puede recibir parámetros sin necesidad de devolver un valor.

Pregunta 4. ¿Para qué sirve la estructura IF?

Permite ejecutar instrucciones diferentes según se cumpla o no una condición.

Pregunta 5. ¿Qué diferencia existe entre COMMIT y ROLLBACK?

COMMIT confirma los cambios realizados. ROLLBACK deshace los cambios no confirmados.

Pregunta 6. ¿Qué función tiene un debugger?

Permite analizar el programa paso a paso para detectar errores y comprobar valores.

Pregunta 7. Indica dos ventajas de utilizar procedimientos almacenados.

Mejoran el rendimiento y permiten reutilizar lógica de negocio centralizada en la base de datos.

Práctica

Trabajaremos con una tabla llamada LIBROS.

Apartado a) - Creación de tabla

Crea una tabla LIBROS con código, título, autor, precio y stock.

CREATE TABLE LIBROS(
   codigo NUMBER PRIMARY KEY,
   titulo VARCHAR2(100),
   autor VARCHAR2(100),
   precio NUMBER(8,2),
   stock NUMBER
);

Apartado b) - Inserción de registros

Inserta tres libros de ejemplo.

INSERT INTO LIBROS VALUES
(1,'El Quijote','Cervantes',19.95,10),
(2,'1984','George Orwell',15.50,8),
(3,'Fundación','Isaac Asimov',22.90,5);

Apartado c) - Procedimiento aumento fijo

Crea un procedimiento que incremente todos los precios un 5%.

CREATE OR REPLACE PROCEDURE aumentarPrecios
IS
BEGIN
   UPDATE LIBROS
   SET precio = precio * 1.05;
END;
/

Apartado d) - Procedimiento con parámetro

Crea un procedimiento que reciba un porcentaje y actualice los precios.

CREATE OR REPLACE PROCEDURE actualizarPrecios(
   p_porcentaje NUMBER
)
IS
BEGIN
   UPDATE LIBROS
   SET precio = precio * (1 + p_porcentaje/100);
END;
/

Apartado e) - Insertar un libro

Crea un procedimiento para insertar nuevos libros.

CREATE OR REPLACE PROCEDURE insertarLibro(
   p_codigo NUMBER,
   p_titulo VARCHAR2,
   p_autor VARCHAR2,
   p_precio NUMBER,
   p_stock NUMBER
)
IS
BEGIN
   INSERT INTO LIBROS
   VALUES(
      p_codigo,
      p_titulo,
      p_autor,
      p_precio,
      p_stock
   );
END;
/

Apartado f) - Ejecución

Ejecuta los procedimientos anteriores.

BEGIN
   aumentarPrecios;
END;
/

BEGIN
   actualizarPrecios(10);
END;
/

BEGIN
   insertarLibro(
      4,
      'Clean Code',
      'Robert C. Martin',
      34.95,
      7
   );
END;
/
